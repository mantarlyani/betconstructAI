# AI-советник BetConstructAI + Gemini — промпт и инструкция

Документ состоит из двух частей:
1. **Промпт** для AI-советника (готов к вставке в Gemini).
2. **Инструкция**: что нужно, чтобы это правильно заработало с Gemini.

---

## 1. Системный промпт (поле `system_instruction` в Gemini)

Это «характер и правила» советника. Его отправляем один раз в каждом запросе как системную инструкцию.

```
Ты — AI-советник платформы BetConstructAI, B2B-маркетплейса решений для iGaming
(беттинг, казино, платёжные системы, платформы, инструменты, лицензии, аффилейт-маркетинг).
Твоя задача — помогать посетителям сайта: понять их запрос, подобрать подходящие продукты
и вендоров ИЗ КАТАЛОГА, объяснить решения BetConstruct и подсказать следующий шаг
(запросить демо / оставить заявку / связаться с менеджером).

ПРАВИЛА:
1. Отвечай ТОЛЬКО на основе данных из блока [ДАННЫЕ САЙТА], который придёт ниже
   (каталог вендоров и продуктов, категории, описания решений, аналитика).
   Не выдумывай продукты, цены, названия, характеристики, лицензии, интеграции или гарантии,
   которых нет в данных. Если нужной информации нет — честно скажи, что уточнишь у менеджера,
   и предложи оставить контакт.
2. Не давай юридических, финансовых и регуляторных гарантий. По вопросам лицензий и комплаенса
   рекомендуй консультацию со специалистом BetConstruct.
3. Отвечай на языке пользователя (русский, английский или армянский) — определяй по его сообщению.
4. Будь кратким и конкретным: 3–6 предложений или короткий список. Не «лей воду».
5. Не запрашивай платёжные данные и пароли. Для заявки достаточно имени и контакта, с согласия.
6. Тон — профессиональный, дружелюбный, экспертный.
7. Если запрошенного нет в каталоге — предложи ближайшую альтернативу из данных и вариант
   «уточнить у менеджера».

ФОРМАТ ОТВЕТА:
- Сначала короткий полезный ответ по сути.
- В конце — одно предложение с призывом к действию
  (например: «Показать демо этого решения? Оставьте контакт — менеджер свяжется»).
```

### Что подаётся в сообщении пользователя (grounding)

Перед вопросом пользователя добавляем актуальные данные сайта — это и есть «анализ базы».
Структура сообщения к Gemini (`contents` → role `user`):

```
[ДАННЫЕ САЙТА]
Категории: Игры, Платёжные системы, Платформы, Инструменты, Лицензии, Аффилейт/Маркетинг.

Вендоры маркетплейса (одобренные):
- {название} · {категория} · регионы: {регионы} · бейдж: {approved/partner} · {краткое описание}
- ...

Решения BetConstruct:
- Turnkey Sportsbook — {описание}
- Casino Suite — {описание}
- Multi-Wallet — {описание}
- ... (из каталога продуктов сайта)

[КОНТЕКСТ ПОЛЬЗОВАТЕЛЯ] (если есть)
Имя: {имя или Гость}; интересовался: {последние разделы/продукты}; корзина: {позиции}.

[ВОПРОС ПОЛЬЗОВАТЕЛЯ]
{текст вопроса}
```

Данные для блока берём из базы Supabase в момент запроса:
- **Вендоры** — таблица `vendors` (только `active=true`): `name, category, regions, badge, description`.
- **Решения** — статический каталог продуктов сайта (описания BetConstruct из index).
- **Контекст** — по желанию: имя из `visitors`, последние события `events` этого посетителя, содержимое корзины.

> Так советник отвечает строго по тому, что реально есть на сайте, и не «фантазирует».

## 2. Инструкция: что нужно для работы с Gemini

### Шаг 1. Получить API-ключ Gemini
- Зайти в **Google AI Studio**: https://aistudio.google.com/apikey
- Войти под нужным Google-аккаунтом → **Create API key** → скопировать ключ (вид `AIza...`).
- Есть бесплатный тариф с лимитами; для продакшена включить биллинг в Google Cloud.

### Шаг 2. Выбрать модель
- **`gemini-2.0-flash`** — рекомендуется: быстрая и дешёвая, хорошо держит инструкции. (Актуальное имя модели проверить в AI Studio — они периодически обновляются.)
- Для более сложных ответов — `gemini-2.5-pro` (дороже/медленнее).

### Шаг 3. Добавить ключ в Vercel (НЕ в код!)
- Vercel → проект `betconstruct-ai` → **Settings → Environment Variables**.
- Добавить: имя `GEMINI_API_KEY`, значение — ключ из шага 1, окружения **Production + Preview**.
- После добавления обязательно сделать **Redeploy** (переменные подхватываются только новым деплоем).

⚠️ Ключ Gemini — секрет. Он должен вызываться только с сервера (Vercel-функция), никогда не из
кода сайта в браузере, иначе его украдут.

### Шаг 4. Серверная функция `api/ai-advisor.js`
Она собирает данные из базы, добавляет промпт и вызывает Gemini. Пример:

```js
// POST /api/ai-advisor  { question, lang, name, context }
const GEMINI_KEY = process.env.GEMINI_API_KEY;
const MODEL = 'gemini-2.0-flash';
const SB_URL = process.env.SB_URL || 'https://smddtvaewmmpuyvtuscb.supabase.co';
const SB_ANON = process.env.SB_ANON_KEY || 'sb_publishable_oPGh3c7PEFreALuOkY6wOA_WovnaNpL';

const SYSTEM = `Ты — AI-советник платформы BetConstructAI ...`; // ← вставить промпт из части 1

async function sb(path){ const r=await fetch(SB_URL+'/rest/v1/'+path,{headers:{apikey:SB_ANON,Authorization:'Bearer '+SB_ANON}}); return r.json(); }

export default async function handler(req,res){
  res.setHeader('Access-Control-Allow-Origin','*');
  res.setHeader('Access-Control-Allow-Methods','POST, OPTIONS');
  res.setHeader('Access-Control-Allow-Headers','Content-Type');
  if(req.method==='OPTIONS') return res.status(200).end();
  if(req.method!=='POST') return res.status(405).json({error:'POST only'});
  if(!GEMINI_KEY) return res.status(500).json({error:'GEMINI_API_KEY not set'});

  const { question, name, context } = req.body||{};
  if(!question) return res.status(400).json({error:'question required'});

  // 1) данные сайта
  const vendors = await sb('vendors?select=name,category,regions,badge,description&active=eq.true&limit=100');
  const catalog = (Array.isArray(vendors)?vendors:[]).map(v=>
    `- ${v.name} · ${v.category||''} · регионы: ${v.regions||'—'} · бейдж: ${v.badge||'—'} · ${(v.description||'').slice(0,160)}`
  ).join('\n');

  const data = `[ДАННЫЕ САЙТА]\nВендоры маркетплейса:\n${catalog||'(каталог пуст)'}\n\n`+
    `[КОНТЕКСТ]\nИмя: ${name||'Гость'}${context?('; '+context):''}\n\n`+
    `[ВОПРОС ПОЛЬЗОВАТЕЛЯ]\n${question}`;

  // 2) вызов Gemini
  const url = `https://generativelanguage.googleapis.com/v1beta/models/${MODEL}:generateContent?key=${GEMINI_KEY}`;
  const g = await fetch(url,{ method:'POST', headers:{'Content-Type':'application/json'}, body: JSON.stringify({
    system_instruction:{ parts:[{ text: SYSTEM }] },
    contents:[{ role:'user', parts:[{ text: data }] }],
    generationConfig:{ temperature:0.3, maxOutputTokens:800 }
  })});
  const j = await g.json();
  if(!g.ok) return res.status(502).json({error:'gemini failed', detail:j});
  const answer = (((j.candidates||[])[0]||{}).content||{}).parts?.[0]?.text || 'Не удалось получить ответ.';
  return res.status(200).json({ answer });
}
```

### Шаг 5. Подключить на сайте (index.html)
В функции AI-советника отправлять вопрос на нашу функцию (а не напрямую в Gemini):

```js
async function askAI(q){
  const r = await fetch('/api/ai-advisor',{ method:'POST', headers:{'Content-Type':'application/json'},
    body: JSON.stringify({ question:q, name: window.USER||'', context:'' }) });
  const j = await r.json();
  return j.answer || 'Извините, попробуйте позже.';
}
```

### Шаг 6. Проверка
- Открыть `https://www.betconstructai.com/api/ai-advisor` (POST) — или спросить что-то в AI-советнике на сайте.
- Должен прийти осмысленный ответ, опирающийся на реальный каталог.

### Что важно для «правильной» работы
- **Грундинг**: всегда подавать свежие данные из базы — тогда советник говорит только правду о сайте.
- **Температура 0.2–0.4** — меньше «фантазий».
- **Лимит токенов** ответа (например 800) — короткие ответы, ниже стоимость.
- **Лимиты/стоимость**: следить за квотой в Google AI Studio; при росте трафика включить биллинг и кэшировать каталог (обновлять раз в несколько минут, а не на каждый запрос).
- **Безопасность/приватность**: ключ только на сервере; не отправлять в Gemini пароли и платёжные данные; для персональных данных — согласие (GDPR).
- **Язык**: советник сам отвечает на языке вопроса (правило №3 в промпте).
